# Politique de sécurité

La candidate HMP V2 est `0.1.0-beta.1`. Les signalements sur cette version et sur le code de `main` sont les plus faciles à reproduire.

Utilisez **Report a vulnerability** dans les [avis de sécurité GitHub](https://github.com/nakuakaben/hyper-media-puller/security/advisories/new) si GitHub propose le formulaire. Si le formulaire est indisponible, contactez le mainteneur en privé par un canal convenu. Les détails d’une faille non corrigée, les secrets, les médias et les rapports non expurgés doivent rester hors des issues publiques.

Incluez la version, le système, le modèle et le firmware si pertinents, les étapes de reproduction et l’effet constaté. Joignez un exemple synthétique et expurgez chemins personnels, adresses, identifiants et contenus des rapports. Coordonnez toute divulgation avec le mainteneur.

Le FTP et le protocole de découverte s’utilisent sur un réseau local de confiance. Le SHA-256 comparé au fichier local vérifie la copie du flux reçu. Une empreinte indépendante du recorder relève d’un autre contrôle.
